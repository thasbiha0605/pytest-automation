Techlistic Practice Form – Pytest Automation

Project Overview

This project automates the testing of the Techlistic Practice Form using Python, Selenium WebDriver, and Pytest.

Tools & Technologies

- Python
- Selenium WebDriver
- Pytest
- PyCharm
- pytest-html
- Git & GitHub

Test Scenarios

The following web elements were tested successfully:

1. Text Fields – Entering user details.
2. Radio Buttons – Selecting gender and other options.
3. Checkboxes – Selecting multiple options.
4. Dropdown – Selecting values from dropdown lists.
5. File Upload – Uploading a file through the form.

Test Execution

Run the following command:

pytest -v

HTML Test Report

Generate the HTML report using:

pytest -v --html=test_report.html --self-contained-html
